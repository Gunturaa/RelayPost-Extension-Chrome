Kebijakan Privasi RelayPost

Terakhir diperbarui: 2026

1. Data yang Disimpan Secara Lokal

Draft postingan, foto/video lampiran, daftar grup, template, jadwal, dan riwayat pengiriman disimpan secara lokal di browser Chrome Anda (chrome.storage.local dan IndexedDB). RelayPost tidak pernah mengumpulkan, membaca, atau mengirim kata sandi akun Facebook Anda ke server eksternal mana pun.

2. Interaksi dengan Facebook

RelayPost menggunakan sesi browser Facebook yang sudah aktif di Chrome Anda hanya saat Anda memulai pemindaian grup, pengecekan kesehatan grup, atau pengiriman postingan yang Anda perintahkan sendiri.

3. Verifikasi Lisensi PRO

Jika Anda mengaktifkan kode lisensi PRO, ekstensi hanya mengirim kode lisensi dan pengenal perangkat acak (deviceId) ke endpoint verifikasi lisensi untuk memastikan status langganan dan batas perangkat yang sah.

4. Penghapusan Data

Anda dapat menghapus seluruh data lokal kapan saja dengan menghapus ekstensi RelayPost dari chrome://extensions atau membersihkan data penyimpanan browser.
