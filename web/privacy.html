Kebijakan Privasi RelayPost

Terakhir diperbarui: 2026

1. Data yang disimpan secara lokal

Draft postingan, foto atau video lampiran, daftar grup, template, jadwal, dan riwayat pengiriman disimpan di browser Chrome Anda (chrome.storage.local dan IndexedDB). RelayPost tidak mengumpulkan, membaca, atau mengirim kata sandi akun Facebook Anda ke server eksternal mana pun.

2. Interaksi dengan Facebook

RelayPost menggunakan sesi browser Facebook yang sudah aktif di Chrome Anda hanya saat Anda memulai pemindaian grup, pengecekan kesehatan grup, atau pengiriman postingan yang Anda perintahkan sendiri.

3. Verifikasi lisensi PRO

Jika Anda mengaktifkan kode lisensi PRO, ekstensi hanya mengirim kode lisensi dan pengenal perangkat acak (deviceId) ke server verifikasi lisensi untuk memeriksa status langganan dan batas perangkat yang sah. Saat Anda menonaktifkan lisensi di ekstensi, perangkat tersebut dilepas dari daftar perangkat aktif.

4. Penghapusan data

Anda dapat menghapus seluruh data lokal kapan saja dengan menghapus ekstensi RelayPost dari chrome://extensions atau membersihkan data penyimpanan browser.

5. Kontak dan dukungan

Jika Anda memiliki pertanyaan terkait privasi, lisensi, atau permintaan penghapusan data perangkat dari server lisensi, hubungi kami melalui email di gunturtriatmaja04@gmail.com.
